Dragon Quest XI (3DS) English Patcher

Play the Japanese-only 3DS version of Dragon Quest XI in English: on a modded 3DS with your cartridge, or in an emulator with your own dump.

On a 3DS with Luma3DS

Download the LayeredFS patch (.zip)
  1. Unzip it to the root of the SD card (it contains luma/titles/0004000000199200/).
  2. Hold SELECT while turning the 3DS on and enable “Enable game patching”.
  3. Start the game from your Japanese cartridge as usual.

For emulators, flash carts or an installed copy: patch your own dump

Everything happens on this page: your game file is never uploaded and nothing needs to be installed.

1 Choose your game

Which file do I need?
  • A decrypted dump of the Japanese cartridge ドラゴンクエストXI 過ぎ去りし時を求めて (title ID 0004000000199200), e.g. made with GodMode9.
  • Trimmed or untrimmed dumps both work; encrypted dumps and .cia files do not.
  • Only the original, unmodified game is accepted; the page checks it before patching.

2 Create the English version

.3ds: for emulators (Azahar, Citra forks) and flash carts.
.cia: to install the English game on a modded 3DS with FBI (needs Luma3DS, which provides the signature patches; replaces an installed copy of the game).
Both are about as large as your dump and are saved like any other download.
On a phone this takes a while: keep this page open with the screen on until the download has finished.

Advanced: use another patch file

The page loads the current patch from this site. To try a different build, pick a .dq11patch file made by the translation tool.
