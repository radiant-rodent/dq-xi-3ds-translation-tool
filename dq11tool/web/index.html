    Official PC translation

    The Steam release of Dragon Quest XI contains the Japanese script next to the official English one. Strings whose Japanese is identical are filled in with the official English automatically (hand edits are kept); for the others the most similar official lines are shown in the editor and given to the auto-translator as reference.

    Import / export translations

    Share work with other translators or edit in a spreadsheet. Imports match strings by their Japanese text.

    Export JSON Export CSV Export all strings (CSV template)

    Auto-translate (machine drafts)

    Creates draft translations for untranslated strings so you can review instead of typing from scratch. Drafts are marked yellow, can be excluded from builds, and are never overwritten unless you ask. Stopping and starting again continues with the strings that are still untranslated. The text is sent to the selected service.

    How to play

    1. Emulator: open …_EN.3ds in Citra/Azahar like any game.
    2. Modded 3DS (Luma3DS): copy the luma folder from layeredfs to the root of the SD card, hold SELECT while powering on and enable “Enable game patching”. Start the game from the cartridge or the installed title.
    3. Modded 3DS (CIA): install …_EN.cia with FBI.
